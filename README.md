## 📌 Why This Extension?

Envato marketplaces (CodeCanyon & ThemeForest) show how many total sales an author has made, but they **never** display their total revenue. 

Because an author might have a **$99** product with 0 sales and a **$65** flagship plugin with over 10,000+ sales, multiplying naive averages produces incorrect numbers.

This extension crawls every product across all portfolio pages and calculates the **true revenue**:

$$\mathbf{\text{Actual Revenue}} = \sum (\text{Product Price} \times \text{Product Sales})$$

---

## ✨ Features

- 🎯 **Accurate Lifetime Earnings**: Calculates true revenue by multiplying each product's specific price by its completed sales count.
- ⚡️ **Multi-Page Pagination Auto-Crawler**: Automatically scrapes all portfolio pages in the background without needing to click "Next".
- 🔲 **List & Grid View Support**: Seamlessly adapts whether the portfolio layout is set to List View or Grid View.
- 🏷 **Accurate Product Count**: Extracts the exact item count from the official *“Currently Viewing”* badge.
- 📊 **Product-by-Product Breakdown Modal**: Click **"View Product Breakdown"** to inspect a full table of each product's individual price, sales, and total revenue.
- 💱 **Real-Time Multi-Currency Converter**: Live conversion from USD into **EUR (€), GBP (£), INR (₹), AUD (A$), CAD (C$), JPY (¥), SGD (S$), BRL (R$), and AED**.
- 🛠 **Browser Toolbar Popup**: Inspect stats from the Chrome toolbar anytime or use the built-in manual calculation tool.
- 🔒 **Privacy-First**: No data collection, no accounts, and no tracking.

## 🚀 Installation (Takes 30 Seconds)

### Step 1: Download or Clone
Clone this repository or download it as a ZIP:
```bash
git clone https://github.com/YOUR_USERNAME/envato-earnings-calculator.git
```
*(If downloaded as a ZIP, extract the folder to your computer).*

### Step 2: Load into Google Chrome
1. Open Google Chrome and navigate to:
   ```
   chrome://extensions/
   ```
2. In the top right corner, toggle on **Developer mode**.
3. In the top left corner, click **Load unpacked**.
4. Select the `envato-earnings-calculator` folder.
5. That's it! The extension is now installed and ready to use. 🎉

## 📖 How to Use

1. Open any author's portfolio on **CodeCanyon** or **ThemeForest**, for example:
   - [Scripteo on CodeCanyon](https://codecanyon.net/user/scripteo/portfolio)
   - [Go-Web on CodeCanyon](https://codecanyon.net/user/go-web/portfolio)
   - [BedigitCom on CodeCanyon](https://codecanyon.net/user/bedigitcom/portfolio)
   - Or any ThemeForest author portfolio!
2. A sleek dark-themed **Author Earnings Summary** banner will automatically appear at the top of the portfolio.
3. Switch currencies via the dropdown in the banner or click **"📊 View Product Breakdown"** to view every item calculated individually.
4. You can also click the extension icon in Chrome's toolbar to view metrics at any time.

## 🧮 How It Calculates Revenue

| Metric | Description | Formula |
| :--- | :--- | :--- |
| **Actual Lifetime Earnings** | The true revenue generated by summing each item individually | $\sum (\text{Item Price} \times \text{Item Sales})$ |
| **Average Product Price** | The arithmetic mean price of all portfolio items | $\frac{\sum \text{Product Prices}}{\text{Total Published Items}}$ |
| **Total Completed Sales** | Total volume of items sold across author's lifetime | From author's official marketplace stats |
| **Approximate Estimate** | Secondary comparison figure | $\text{Total Sales} \times \text{Average Price}$ |
